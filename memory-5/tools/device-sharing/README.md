# Sekai 电脑供音客户端（Windows）

让同一账号的其他设备播放这台电脑上的音视频、歌词和封面。服务器只中转播放数据，不保存媒体文件。网站必须已启用设备共享。

## 第一次使用

1. 安装 Node.js 22 或更新版本（已有无需重复安装）。解压客户端到普通文件夹，不要从 ZIP 内运行。
2. 登录 https://sekaisong.com ，在“设备共享”页生成一次性配对码，五分钟有效，不要发给别人。
3. 双击 `start-sharing.cmd`。网站地址直接回车，粘贴配对码，填写设备名称。
4. 输入歌曲文件夹完整路径，每行一个，最后空行回车结束。最多 16 个目录，包含子目录。仅匹配该账号歌曲库已有歌曲，不自动新建歌曲；首次导入仍在网站完成。
5. 等待匹配完成，在网站“设备共享”页看到设备在线后开启共享。
6. 另一台电脑或手机登录同一账号，从原歌曲库或歌单进入演出。供音电脑必须开机、联网，保持客户端运行。

## 以后使用

再次双击启动器会读取保存的设备和目录索引，不用重复选文件夹。**客户端重启或网络重连后，共享默认关闭**；网站账号登录退出不会清除客户端关联。重新开启共享使用网站开关。

在本机输入命令后回车：

- `stop`：停止共享并禁止网站重新开启。
- `resume`：解除本机禁止，仍需到网站开启。
- `rescan`：停止共享并重新选择目录，匹配新增或移动后的文件。
- `quit`：退出客户端。

关闭窗口也会停止供音，其他设备已缓冲的片段可能还能播放片刻。撤销设备后旧凭证失效。

## 匹配和安全

音视频按歌曲库记录的文件名、大小匹配，多个候选不擅自选择。LRC、封面放在媒体同目录，主文件名相同，例如 `song.flac`、`song.lrc`、`song.png`。不读取快捷方式、符号链接或 junction。源文件删除或大小改变后拒绝读取，需要整理并重新扫描。

配置保存在当前用户 `%LOCALAPPDATA%\SekaiSong\DeviceSharing`。凭证由 Windows 当前用户加密，不能将配置复制到朋友电脑使用。客户端包不含网站密码、部署密钥或歌曲。仅本人账号访问，不生成公开下载链接，最多两路同时传输。

播放消耗电脑上传带宽和服务器中转带宽。客户端不设开机自启，不打开电脑入站端口。

## 验证范围

自动化测试使用临时文件，覆盖索引持久化、Windows 凭证加密、真实 WebSocket／HTTP 全量和 Range 传输、账号隔离、停止／恢复及重连后默认关闭。异地实体设备、浏览器的视频编码和完整演出观感仍需单独验收。
