Sekai Song 私人实测邀请（Windows 10 / 11）

1. 把整个压缩包解压到桌面，不要直接在压缩包里运行。
2. 双击 start-test.cmd，会自动连接并打开 http://localhost:18085/login。
3. 用站长另外提供的账号密码登录。这个包不包含账号密码。
4. 保持连接窗口打开；测试结束按窗口中的回车键。直接关闭窗口后，请另运行 stop-test.cmd。

邀请码有效至北京时间 2026年10月18日12:10，站长也可以提前撤销。
包内 preview_key 是这次邀请的专用钥匙，只能访问测试网站，不能登录服务器命令行、SFTP或数据库。不要转发到群聊或公开网盘。
站长后台和删除操作在这个入口禁用；歌单字段、收藏和播放设置仍可能同步到你登录的账号。用共享账号时请先征得站长同意。

重要：账号里保存的是歌曲信息与歌单，不是音频。你必须关联自己电脑里的对应歌曲，或请站长另外发一首音频给你；网站不能读取站长电脑上的音乐。测试包不含音乐。
推荐使用最新版 Edge / Chrome，并开启浏览器硬件加速。演出在你的电脑上渲染，私有连接不会解决所有显卡/浏览器卡顿问题。

常见问题：
- 提示缺少 OpenSSH：Windows 设置 → 应用 → 可选功能 → 添加 OpenSSH 客户端（免费），然后重试。
- 提示18085端口占用：先运行 stop-test.cmd；不要关闭与此测试无关的软件进程。
- 连接失败：检查是否能访问服务器SSH端口22，或者邀请已到期/被撤销；将 connection.log 发给站长排查。
- 下载页面慢与演出卡顿是两种问题，请记录浏览器版本、硬件加速状态和出问题的演出类型。
