01 自行准备 FLAC / MP402 匹配歌名、封面和 LRC03 关联已有歌曲或直接导入
文件怎么放？查看格式、歌词匹配与常见问题

先自行准备 FLAC 和 MP4。推荐把同一首歌的音频、视频、LRC 和封面放在同一个文件夹，名称相同、扩展名不同；选好文件后点“匹配歌名、封面和 LRC”。

选好真正存放文件的位置：请选择磁盘上的实际文件夹，避免快捷方式或跳转目录。若出现“找不到文件或目录”，请直接打开真实目录后重新选择。

推荐的文件夹示例

我的音乐/
├─ 花の塔.flac
├─ 花の塔.lrc
├─ 花の塔.jpg
├─ 天外来物.mp3
├─ 天外来物.lrc
├─ 天外来物.png
├─ 视频歌曲.mp4
├─ 视频歌曲.lrc
└─ 视频歌曲.png

支持子文件夹，例如按专辑分类；对应的音频、歌词和封面仍要放在同一层。

自动匹配怎么判断？

  • 优先读取内嵌信息：音频有内嵌封面或带时间戳的歌词时，不必另外准备文件；同名外部文件可补充或替换。
  • 外部文件要同名：花の塔.flac 对应 花の塔.mp4、花の塔.lrc 和 花の塔.jpg。文件分组按名称匹配，站内歌曲优先按内嵌歌名和歌手精确匹配。
  • 支持的格式：音频 MP3、FLAC、M4A、WAV、OGG、AAC、OPUS；视频 MP4、WebM、MOV（取决于浏览器编码支持，推荐 H.264/AAC MP4）；歌词 LRC；封面 JPG、JPEG、PNG、WEBP。
  • 视频播放：视频只播放原画面和原声音轨，不提取 WAV，也不用于歌词演出。
  • 导入与关联不同：新视频选择后检查结果，确认加入歌曲库或歌单。已有歌曲或视频先选择网站歌单，再选本机文件夹，逐项核对匹配后确认关联。视频改过名时，可以手动指定对应歌曲。
  • 歌词要有时间戳：LRC 推荐 UTF-8 编码，例如 [00:14.250]歌词内容。没有同步歌词也能听歌，但不能完整展示同步歌词演出。
  • 选择方式：选择音乐文件夹会扫描其子文件夹；选择单首音乐时，可同时选择对应的歌词和封面。缺失信息也可在打开歌曲后补充。
  • 确认保存位置：检查匹配结果，再选择歌曲库、已有歌单或新歌单，最后确认导入。选择歌单时，歌曲也会保存到歌曲库。

文件名比较长也没关系：2-36-1778404055914.flac 对应 2-36-1778404055914.lrc 和 2-36-1778404055914.jpg，页面仍可从内嵌标签读取“花の塔”。注意不要把歌词误命名为 .lrc.txt。

文件保留在你自己的设备：网站不上传音频或封面，也不会自动传到手机。导入后移动、改名或删除文件，可能需要重新关联；换设备也要选择新设备上的对应文件。支持的浏览器会记住只读文件授权，其他浏览器下次可能需要重新选择。网站不会移动或删除你的原文件。

各歌单还缺什么

按当前浏览器已保存的关联检查。QQ 歌单提供的专辑封面、已关联的本机封面或音频内嵌封面都会算作有封面；只有三者都没有才提示缺封面。音视频与 LRC 不会因为歌曲出现在其他歌单就算作已关联。
