# 网站评论与管理概览交付

本机入口：`/feedback`（评论区）、`/admin/overview`（站长概览）。原登录、注册、音乐文件与账户密码不变；侧边栏新增入口。

听友广场更新：主评论与楼中楼、点赞（按账户去重）、最新/热门排序、表情输入、站长标识。所有评论与回复均审核后公开；主楼撤下后回复不可公开，自己可看到“已审核但原楼未公开”。UI示例测试数据仅由独立浏览器API替身提供，没有写入真实数据库。验证脚本为 `tools/local-player/community-browser-qa.mjs`。

已有云端评论表升级时，由数据库管理员先运行 `feedback-overview.sql`，再运行幂等 `listener-plaza-upgrade.sql`，核对新点赞表的SELECT/INSERT/DELETE权限，再更新JAR；不要依赖低权限应用账户执行ALTER TABLE。新部署的完整建表脚本已包括字段与点赞表。本轮未操作云服务器。

评论区只保留文本框和发布按钮，不要求实用性、创新性评分。登录用户可提交2～1000字，每分钟一次，默认为待审；仅管理员可通过或撤下。本人可展开“我的留言”查看状态，公众仅见已公开评论。分页20条，导出最近10000条UTF-8 BOM CSV，防公式注入。旧评分列保留且允许NULL，避免删掉潜在历史数据，新功能不写评分。

管理员授权使用服务端配置 `sekai.website.admin-user-id`，默认现有sekai账户ID 3。服务器端逐接口检查权限，不靠隐藏导航；全部写接口校验session CSRF。评论作为文本显示，不能执行HTML。API禁止缓存个人与管理数据。

统计记录成功登录、实际播放会话和四种演出时长。按北京时间日统计，暂停/缓冲/拖动不算，累计5秒才算一次播放；切换演出保留同首会话。客户端累计上报幂等，服务端按照实际经过时间和单次30秒上限限制增量。只传编号、模式、累计毫秒，不传音频/封面/绝对路径。异常关闭、网络中断或后台节流可能漏报，不用于计费与精确审计。

新增表由 `src/main/resources/db/feedback-overview.sql` 定义。后续部署云服务器时，先由数据库管理员执行该脚本，核对应用账户对新表的SELECT/INSERT/UPDATE权限，再更新JAR并重启；不要把数据库3306或应用8085对公网开放。当前只更新本机，云服务器未同步，未恢复备案期间关闭的域名。

验收：`mvn -q -o test`；`node tools/local-player/listening-unit.mjs`；设置环境变量SEKAI_QA_PASSWORD后运行`feedback-browser-qa.mjs`（仅真实登录、读取，评论HTML注入测试使用浏览器API替身）、`listening-browser-qa.mjs`（真实本地MP3播放、跳进度、暂停，无偏好写入）。

真实数据库评论测试全部回滚，无测试评论残留。真实浏览器播放约6.447秒计1次，跳过70秒未多算，暂停不增长；测试OPFS副本仅在D盘独立浏览器里生成和清理，B盘原音频保留。导入/播放既有测试继续通过。
