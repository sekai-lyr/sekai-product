## 持久化边界和仍需用户完成的步骤

数据库保存原有歌曲字段、文件名/大小和设备身份。真实目录、相对文件路径和加密设备凭证保存在供音电脑当前 Windows 用户目录；在线媒体目录由客户端每次连接重新登记，服务端内存持有。这不需要重新扫描或重新关联，也不上传本地绝对路径。

用户仍需首次运行客户端、配对并选择真实目录；本次没有擅自为 sekai 账户开放真实文件。关闭客户端或电脑离线时不能供音。浏览器已缓冲的数据不能撤回。

没有声称验证异地实体手机、所有浏览器视频编码或长时多人负载；公网测试使用独立 HTTP 播放端进程，不冒充朋友电脑的实际验收。
