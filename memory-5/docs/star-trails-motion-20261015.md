# 星轨动效增强

仅调整第 19 种星轨演出，其余演出及页面布局保持不变。

- 同档位旋转系数由 0.004 提至 0.048，保留速度滑块和零速静止。
- 自动天空从可见星点的暮色开始，7 秒入夜，替代此前约 20 秒过渡。
- 提高细星轨亮度及尾部可见度，略增线宽；不移动歌词。
- 保留音频时间驱动、暂停静止、回拖复现及减少动态偏好。

验证：

- `node tools/folia/star-motion-test.mjs`：5 项检查通过，1440×900 默认速度下 422 个共同星点的一秒位移中位数 23.31px。
- 浏览器：1440×900、1024×640，设置与进度跳转通过；真实音频连续播放约 1.27 秒时画布变化，暂停后画布稳定。
- 性能采样约 22.65ms/次完整渲染，仅代表本次测试设备，不代表所有用户设备帧率。
- Maven 发布构建：33 项测试通过。
- 浏览器仅出现已有的 favicon.ico 404，无演出脚本异常。
