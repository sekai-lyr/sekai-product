# 视频导入与关联修复

## 根因

1. 账户目录只从旧 `local_audio_url` 推导文件名，忽略了 `local_video_url`。没有浏览器绑定记录的视频无法按文件名批量关联。
2. 旧上传视频表单替换后的链接丢失歌曲编号和歌单上下文；在歌曲页选择改名视频又走新歌曲导入，可能重复建歌。
3. 确认关联后，当前歌曲已经预读取完成，原有条件不再重新选择它，空舞台无法恢复播放。
4. 切换演出会重建 iframe，视频原画面总是重新显示，覆盖歌词演出。
5. 浏览器不支持持久文件句柄时，新文件选择可能留下旧句柄，重新打开后误播旧文件。

## 改动

- 目录响应增加仅含文件名的 `videoFileName`；缺音频文件名时回退到旧视频文件名，不返回本地绝对路径。
- 批量关联可匹配已拥有的视频文件名。旧入口保留歌曲与歌单，明确“关联本首本地视频”。
- 单首关联预览、确认与新建导入分开；一次只允许一个媒体文件，可附同名 LRC/封面；确认前不保存。
- 单首关联不新增歌曲、不改变歌单，保留原标题；关联完成原地播放。
- 视频原画面和歌词视图状态在同一播放会话中保留，选择演出时显示歌词。
- 非持久文件选择清空旧引用；不复制视频到服务器或 IndexedDB。目录与文件句柄仍由用户手动授权。

## 验收

真实数据库测试使用 QA 账户并事务回滚。浏览器测试拦截账户接口，视频为 16KB 合成测试片，句柄存在隔离 Chrome 的 OPFS，不修改 sekai 歌单。

- `tools/test-video-association.mjs`：改名视频定向绑定、多个媒体拒绝、未知账户歌曲拒绝、旧视频批量匹配。
- `tools/test-video-entry.mjs`：旧视频入口保留歌曲、歌单和媒体上下文。
- `tools/test-existing-playlist-link.mjs`：三个已有歌单与共享歌曲关系不变。
- `tools/local-player/video-import-flow-qa.mjs`：预览零写入、确认关联、同名 LRC、刷新恢复、新视频导入指定歌单、批量关联、未知文件跳过、非持久输入不恢复旧引用、切换演出不被视频覆盖。
- `tools/local-player/import-flow-qa.mjs`：既有音频导入、封面与歌词、句柄恢复、原四种演出回归。
- `tools/folia/local-video-qa.mjs`：单一音轨、暂停/跳转同步、原画面切换、WAV 提取。
- `tools/local-player/layout-qa.mjs`：1440/390 宽度，侧栏保持，页面无横向溢出。

本修复不自动打开公网访问。视频能否解码仍取决于浏览器，推荐 H.264/AAC MP4；缺 LRC 不等于导入失败。
