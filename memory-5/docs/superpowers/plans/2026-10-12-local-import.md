# 本地音乐导入原歌曲库与歌单

目标：用户已批准的选择文件、预览匹配、选择歌曲库或歌单、确认导入流程；音频和封面不上传。

架构：沿用账户字段和 IndexedDB 文件句柄；导入页和歌曲播放入口共享现有播放实现，不另建歌曲库。匹配结果使用 textContent；保存接口校验登录、CSRF、歌曲与歌单所有权。

技术栈：现有 Spring Boot、Thymeleaf、原生 JavaScript、MySQL。
