# 网站评价与管理数据概览

目标：用户已批准的登录评价、审核后公开与仅管理员可见的运营数据概览。

架构：新增独立反馈、登录日统计、听歌会话和演出日统计表，不修改用户密码或音乐数据；复用现有会话和页面外壳。管理员使用配置中的账户ID（默认现有sekai用户3），不是靠前端隐藏实现授权。

- [x] 真实数据库事务回滚测试：未登录/非管理员拒绝、待审不公开、审核后公开、评论限频、听歌累计请求幂等、时长不超过服务端经过时间。
- [x] JdbcTemplate参数化查询与验证DTO；新表启动迁移，CSRF保护全部写操作，公开评论分页，管理员导出CSV防公式注入。
- [x] 登录成功才记录日统计；本地播放器只在audio实际播放时累计墙钟时间，每10秒上传小字段，暂停、等待、拖动不计；切换演出不重置同一首会话。
- [x] 新评论区、仅sekai可见的数据概览页；卡片、近7天趋势、四种演出时长、评论审核和CSV导出；沿用原侧边栏和主题。根据用户最新反馈，去掉评分，改为单输入框和发布按钮，2～1000字。
- [x] 离线全量测试、同步本机并重启；浏览器检查管理员/访客、桌面/手机、HTML注入安全。真实数据库功能测试使用账户31并事务回滚；真实登录和6.447秒本地播放QA保留为真实统计（1次播放），没有留下测试评论；不部署公网。

统计口径：注册人数来自现有账户；新增登录与播放指标从启用后开始累计。播放会话累计至少5秒计一次；听歌时长是实际播放墙钟时长，不是歌曲进度，倍速不翻倍。断网、异常关闭可能漏报；近5分钟活跃人数不宣称精确在线人数。评论不要求评分，数据概览不再展示评分均值。公开区显示昵称而非文件路径/账户密码。
