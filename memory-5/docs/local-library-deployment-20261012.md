## 用户首次关联

在自己的日常浏览器打开本机 /local-player，登录sekai，点击“关联文件夹并记住”，选择 B:/Sekai/Sekai/sekai/memory-5/uploads/audio。浏览器授权不能由服务器替代，也不能从测试浏览器移植到日常浏览器。将来改用正式域名或换设备，需要在该浏览器再次授权。
