# 本地音乐站体验与歌库管理改进

## 页面入口

- 登录：手机首屏展示登录表单，外观选择移到表单后。
- 首页：继续听、真实最近播放、收藏与常用歌单优先展示，统计位于后方。
- 歌曲库 `/songs`：封面展示与紧凑列表切换；无歌曲和无搜索结果分别提供引导。
- 播放 `/player/{id}`：优先展示舞台与播放控制；文件关联、补充素材和歌单检查折叠到工具区。文件不可用时自动展开工具。
- 歌库整理 `/library-tools`：侧栏入口，包含智能歌单、重复歌曲检查、备份恢复和导入任务。

## 新增能力与边界

### 智能歌单

最近 30 天导入、最近 30 天常听、缺少歌词、尚无文件关联记录四种筛选。结果按当前账号隔离，每页 30 首。关联记录不能代替浏览器文件授权；换设备仍须重新关联。

### 去重合并

同名、同歌手仅列为候选，不自动删除。可选择保留第一首或第二首，预览后确认。合并保留收藏、歌单成员、听歌记录，并在保留歌曲字段为空时补充另一首的资料。已有歌词和播放偏好以保留歌曲为准。预览后歌曲资料变化将要求重新预览。

浏览器中关联到被移除歌曲编号的文件句柄不能通过服务端搬移，必要时需为保留歌曲重新关联。建议合并前下载资料备份。

### 备份恢复

JSON 版本 1，包含歌曲资料、歌词、收藏、歌单成员和播放偏好，不包含账号密码、音视频、本机封面或文件授权。最多 5000 首歌曲、500 张歌单、8 MB。

恢复必须先预览，显示匹配冲突后选择：

1. 跳过已有歌曲，保留当前资料。
2. 补充已有歌曲的空白字段，合并收藏，保留已有偏好。

歌曲按标题、歌手、专辑匹配，歌单按名称合并；重复恢复不会重复新增成员。备份中的旧编号仅用于重建成员关系，不会用来读取其他账号资料。恢复为事务操作，非法引用、字段或偏好将拒绝写入。

### 导入任务

网易云、QQ 导入页面启用后台任务；保留原同步表单路由供无脚本环境使用。每行一个链接或歌曲编号，最多 5000 行、120000 字符，每个账号最多 3 个排队或运行中的任务。

任务持久化到 MySQL，按输入项展示完成进度、消息、新增与跳过数量。只有未完成项可重试；能获得缺失歌曲编号时按编号重试，平台未返回缺失编号时重新读取对应失败歌单，由原有去重逻辑跳过已导入歌曲。服务重启后，运行中的任务标记为中断，可手动重试；排队任务继续处理。当前为单应用实例、单后台工作线程，未引入外部队列。

## 数据与查询

首页使用数据库统计和限量查询；搜索在数据库中过滤、计数和分页；歌单详情直接分页查询。最近播放来自实际听歌记录，不再以资料更新时间代替。

启动时 `SongSchemaMaintenance` 增量创建 `sekai_song_import_task`，并检查补充歌曲最近导入、听歌记录查询索引。不会执行初始化 SQL 中的删除表操作。

## 本地启动与验证

使用 README 中的数据库环境变量启动即可，默认仍为 8085。新功能首次启动需要当前数据库账号具有新增表和索引的权限。

本次回归使用独立数据库 `sekai_song_features_20261028`，未向服务器部署。测试命令需先将 `DB_URL` 指向独立测试库并设置本机凭据：

```powershell
mvn test package
```

浏览器检查脚本仅允许 `127.0.0.1`，需要隔离预览端口 18085、`qa_layout` 测试账号与测试曲目，不应连接个人歌库：

```powershell
node tools/browser-qa-runtime/verify-library-improvements.cjs
```

截图与浏览器检查结果保存于 `qa-output/library-improvements/`。测试音频为脚本生成的 WAV，在浏览器本地关联与播放。

最终验证：`mvn test package` 通过，88 项测试零失败；最终打包后 23 项浏览器检查通过、无页面脚本错误，包含 390/768/1440 三档宽度、备份恢复、重复候选预览、导入失败进度及本机 WAV 关联播放。外部平台导入成功路径使用模拟数据回归，本次未向平台发起真实歌单导入。
