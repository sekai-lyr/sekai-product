# 朋友Windows私测入口

专用服务器SSH账户 `sekai-preview`，只可转发到loopback的8081预览网关。MaxSessions0、ForceCommand false、禁止PTY/SFTP/代理转发/远程端口转发/其他目标端口；新网关仍只监听127.0.0.1，公网80/443保持503。根账户、应用账户和数据库账号密码未改。

邀请专用Ed25519钥匙，不是部署/root私钥。服务器主机公钥通过现有可信管理员连接核对后固定在known_hosts，客户端不自动信任未知主机。2026-10-13延长测试，截止北京时间2026-10-18 12:10：authorized_keys到期拒绝新连接，持久systemd timer清空这份测试授权并杀掉该测试账户的连接进程。提前撤销执行 `/opt/sekai-preview/preview-revoke.sh`，不影响root管理或网站程序。

测试地址 `http://localhost:18085/login`，先运行邀请包里的start-test.cmd建立私有连接；只发链接不能访问。SSH传输加密，客户端监听地址只为127.0.0.1。包不包含网站账号密码、root钥匙或音乐。朋友登录共享sekai会看到641首字段记录，需要自己选择音频；网关禁止站长后台和删除，但收藏、字段关联、播放设置等仍可能改变共享账号。只给可信朋友，推荐后续使用独立普通账户。

测试过程中修正了PowerShell系统代理影响健康探针，以及Nginx转发丢失18085端口导致登录后跳到本机80的问题。更新版一键连接显示ready；真实Chrome已登录/home并进入账户歌曲界面。最终组合自动检查被工具策略拒绝，没有换手段绕过。浏览器最终完整断言因限时测试通道结束尚未完成；不能声称朋友设备演出性能已经验证。服务器已验证网站200、后台/删除403，实际命令通道被拒绝、远程转发被拒绝，有效PermitOpen仅8081。

客户端为Windows10/11自带OpenSSH，缺失时用户自行安装Windows可选功能。正常启动保持控制窗口，按回车结束；强关窗口后需执行stop-test.cmd，仅停止匹配专用账户、钥匙路径的SSH进程，不杀其他SSH。
