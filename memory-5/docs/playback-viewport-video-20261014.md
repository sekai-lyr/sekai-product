# 桌面演出适配与本地视频（2026-10-14）

本轮保留歌曲库、歌单和全屏舞台结构，调整歌词在实际窗口中的尺寸和镜头边界。

- 商籁及字符浮现的 Sonnet：在镜头变换后测量实际字形边界，缩放、平移至上下按钮之间的区域。
- 凝彩：默认启用原版整句选项；文字镜头边界受约束。窗口尺寸变化时按当前音频时间重建渲染器，避免旧滤镜表面导致的崩溃；此时可能出现短暂重绘。
- 心象：检测最终缩放后的字块碰撞，有碰撞时保留字号层次并重新分行。
- 云阶：为字块留出空间，限制额外放大与位移。
- 浮名：约束当前句镜头范围，暂停时跳转也重绘。
- 镜台：跳转后重新定位镜头，普通 LRC 的镜头按整句中心取景，文字越界时回正并调整距离。
- 原版画廊按可用宽高计算字号，并监听窗口变化；五种衍生演出使用布局尺寸，重置绘图状态以保证同一时间画面一致。
