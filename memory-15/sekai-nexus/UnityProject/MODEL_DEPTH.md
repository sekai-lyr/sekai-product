# 环境模型精修 · 第一轮

## 范围与造型约束

默认环境优先：阔叶树、杉树、岩石、草叶。保持已有卡通配色、地形、固定种子分布、碰撞、角色、操作及存档不变。这里是 Unity 原生网格精修，不是图生 3D 后端或 Blender 雕刻产物。

沿用“3D建模”技能的轮廓优先顺序：先确认整体树形与分枝，再添加叶簇、树根、破面等次级结构，最后检查游戏光照下的效果；不借环境精修改动小智比例。

- 阔叶树：微弯分段树干、根部外张、主枝/次枝、扁平错层叶簇、外围折叠叶片。保留约 9m 高的阔冠轮廓。
- 杉树：保留约 10m 的尖塔轮廓，实体锥体替换为放射状枝条和参差的针叶扇面。
- 岩石：不规则断面、错开的岩层、局部苔藓。固定顶点颜色，不引入外部纹理。
- 草：弯曲且渐细的分段叶片，底部暗、叶尖亮；小花具有花茎、花瓣及花心。
- 近远景使用同一构型的不同细节级别，保持远处轮廓，不将所有新几何绘制到地图尽头。

## 验证计划

1. 检查四类近/远网格：索引、有限坐标、颜色/法线、三角形预算、轮廓边界。
2. 实际 Unity 渲染单体近景及正面/左右/背面轮廓；游戏截图复用上一版机位。
3. 回归大世界路线、过桥、水岸限制、遭遇/捕捉、地图点击、存档序列化。
4. 分别采样原野与森林帧时，记录测试条件，不把封顶 60 FPS 的采样当成全地图性能保证。

## 2026-10-01 验收结果

- `model-depth-build.log`：`OPEN_WORLD_BUILD: Succeeded`，无 C# / shader 编译错误。
- `model-depth-runtime.log`：`WORLD_REVIEW_OK`。实际控制器沿三条路线移动 865.0m；过桥、水岸限制、遭遇、捕捉、返回、地图 UI 点击和存档 JSON 往返均通过。测试不写用户冒险存档。
- 四类模型的近/远三角形数：阔叶树 7,440 / 3,264；杉树 9,956 / 2,448；岩石 415 / 81；草簇 166 / 66。网格通道、坐标有限性、索引、预算及近远景边界检查通过。
- 近景范围：树 85m，岩石 65m，草 38m；更远处使用简化模型。按实例距离选择，批次预裁剪额外包含格子半对角线，避免格子中心先被裁掉而漏掉近处植被。当前为离散 LOD，未实现渐隐过渡。
- 生成 24 张单体图（四类模型各五方向近景及一张远景），复用原来的游戏机位输出九张地图/玩法图。检查了原野、森林及模型近景，全部是 Unity 实际网格渲染，没有生成概念图替代游戏画面。
- RTX 5060 Laptop GPU，1440×900、4× MSAA、60 FPS 上限，两个地点各预热 30 帧再取 120 帧：原野与森林帧时中位数/P95 均 16.67ms；渲染加 GPU 同步读回中位数分别 6.23 / 6.87ms，P95 分别 8.58 / 10.34ms。Unity 分配约 85MiB，不代表进程总内存或显存。
- 性能测试显式 `Camera.Render()`，并以 1 像素 `ReadPixels` 等待 GPU 完成。早期隐藏窗口只采样帧循环，不能证明真实渲染性能；这里替换了该方法。采样为场景相机，不包括屏幕叠加 HUD，也不是全地图压力测试。
- `model-depth-legacy.log`：`ASH_REVIEW_OK`，17 骨骼、走跑跳、蒙皮、碰撞和旧地图往返通过；未做桌面键鼠人工跑图。
