# ADR-001：第一阶段采用模块化单体

## 状态

已接受。

## 背景

Sekai World Engine 同时包含身份、世界、角色、关系、模拟、故事和时间线等领域。第一阶段目标是尽快验证一个小世界真正运行起来，而不是提前解决分布式部署。

## 决策

使用一个 Spring Boot 应用和一个 MySQL 数据库。代码按领域模块分包，每个模块内部保持 controller、service、mapper、model 分层；跨模块依赖通过 service/domain DTO 表达。

## 后果

- 简化本地启动、事务边界和集成测试。
- 模块边界仍然清晰，后续可在真实瓶颈出现时拆分。
- 需要持续避免共享巨型 service 和跨模块直接 mapper 访问。
