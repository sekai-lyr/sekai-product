# Sekai World Engine — 产品与架构蓝图

本文件是 `plans/sekai-world-engine-blueprint.md` 的可读版入口。项目第一阶段只构建一个可持续运行的小世界：规则驱动、时间推进、事件记录、选择干预和历史分支。

## 一句话产品定义

一个由确定性规则驱动的原创虚拟世界：世界会自己运行，而用户的选择会留下可以回看的后果。

## MVP 验收路径

注册 → 登录 → 创建种子世界 → 查看世界总览 → 推进一天 → 查看事件 → 处理选择 → 查看状态变化 → 从历史节点 fork 分支。

## 关键设计约束

1. 相同 seed、逻辑日期和状态得到相同模拟结果。
2. 重要变化不可静默覆盖，必须生成时间线和状态差异记录。
3. 世界状态只来自数据库和事务内 domain service，不放入全局内存。
4. 先实现一个小世界闭环，再添加 Creator Studio、多世界分享和 AI 辅助。

详细的领域模型、表结构、接口、阶段任务、风险和 ADR 见 [构建蓝图](../../plans/sekai-world-engine-blueprint.md)。
