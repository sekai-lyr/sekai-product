# Sekai Anime Video Hub 设计说明

## 方向

本次前端以“深夜录像租赁店的索引柜”为视觉隐喻。它把散落的看番站点整理成一张可快速取用的索引，而不是把产品伪装成内容库。

- 基调：深夜城市、安静、可靠、可检索
- 主色：墨蓝背景、纸白信息层、信号橙操作色
- 形态：索引条、标签页、播放器框、低层级边框
- 图片：`src/main/resources/static/images/sekai-night-route.png`
- 图片用途：落地页主视觉、登录/注册分屏背景、空状态与看板视觉

## 颜色与排版

CSS 变量集中在 `src/main/resources/static/css/app.css`。页面使用系统无衬线字体，保证中文环境无需额外字体网络请求。

- `--ink`：全局墨蓝背景
- `--surface`：站点卡片与工具栏层
- `--paper`：主要信息文字与浅色信息面
- `--muted`：次要说明
- `--accent`：按钮、焦点、索引状态与关键提示
- `--line`：低对比度分隔线

圆角保持在 8px 至 18px 的范围内。信息卡使用边框和层级区分，不使用泛化的玻璃拟态或渐变文字。

## 页面映射

- `/`：从主视觉和三条功能索引说明产品价值，入口指向注册或登录
- `/login`、`/register`：复用城市路线图的分屏认证界面
- `/home`：搜索、分类、热门站点与站点索引，是主要工作台
- `/dashboard`：统计、分类、热门站点和可继续浏览的看板
- `/anime`：播放器、推荐站点和快捷入口，优先保证看番路径
- `/anime-hub`：外部聚合站点的标签栏、嵌入区与失败回退

所有既有后端表单 action、字段名和路由保持不变。

## 动效

动效只表达进入、焦点、打开、关闭和加载状态。`effects.js` 使用原生 Web Animations API 与 `IntersectionObserver`，没有全屏粒子循环或滚动监听。统计数字使用短促的计数递进，卡片使用指针位置聚光，按钮使用涟漪反馈；这些反馈都只在对应交互发生时出现。

- 首屏：标题、索引条、主视觉依次进入
- 工作台：工具栏、统计和站点条目按层级出现
- 交互：按钮、卡片、模态框提供短促反馈，成功提示自动收起
- 聚合页：外部 iframe 加载时显示连接状态，加载完成后淡入
- 看番页：小窗和全屏模式使用统一的打开/关闭过渡
- `prefers-reduced-motion`：关闭非必要过渡和延迟

## 可访问性与响应式

输入框保持清晰标签、较高对比度和可见焦点环。页面支持键盘关闭模态框，认证页和工作台在窄屏下切换为单列布局，站点标签栏支持横向滚动。
