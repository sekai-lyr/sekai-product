一个基于 **Spring Boot** 的动漫视频站点导航/聚合项目，作为动漫流媒体站点入口。

## 功能

- 动漫视频站点聚合与导航
- 站点跳转（redirect）服务

## 项目结构

- `SekaiAnimeVideo/`：Spring Boot 主项目
  - `database/`：数据库脚本
  - `src/`：源码（control / service / dataobject / model 分层）

## 运行

```powershell
cd SekaiAnimeVideo
mvn spring-boot:run
```

## 说明

- 根目录的 `一键看番.bat` 用于启动服务并打开浏览器。
- 本地调试脚本、运行日志、Cookie 和测试截图不属于项目运行所需文件。
