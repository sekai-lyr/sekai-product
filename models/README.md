# models · Live2D 模型库

二次元 Live2D 角色模型资源库，用于多个 Sekai 项目（如 anime_rpg、SekaiForm 等）中的角色展示。

## 目录

- `2d/`：2D Live2D 模型
- `3d/`：3D 模型（如有）

## 内容

包含 Live2D Cubism 模型文件：

- `.moc3`：模型文件
- `.model3.json`：模型配置
- `.physics3.json`：物理效果配置
- `.motion3.json`：动画动作（idle / home / login / mail / main 等）

## 使用

配合 Live2D Cubism SDK（如 pixi-live2d、Godot Live2D 插件）加载使用。
