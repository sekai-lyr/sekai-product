每人独立 5 秒，16:9，目标 MP4 / H.264，角色实际动作与运镜。分镜、参考图和输出路径见 production.json。现有参考图为官方头像；生成时需检查服装与身体细节的一致性，不将自动补全视为已核实设定。

## 触发设计

- 普通合成继续使用简短得分反馈，不播放视频。
- 首次在实际游玩中合成 512、1024、2048、4096 时，播放该角色 PV。512 作为高阶起点，是待实现的默认值。
- 成就解锁时播放当前最高阶角色 PV，12 位角色全部具备素材映射。
- 同一步的多个成就与高阶解锁合并为一次演出，优先展示高阶角色；载入存档不补播历史成就。
- 播放时暂停输入和游戏计时；提供跳过、关闭与静音控制；结束或失败后恢复先前状态。
- 播放失败保留成就文字提示；不影响得分、存档或继续游戏。
- 不预加载全部视频，只加载待播放素材；不会把尚未生成的路径挂入线上播放逻辑。
