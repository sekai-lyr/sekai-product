# 抽签角色动态 PV 实现计划

目标：延续现有抽签接口，用角色立绘提供揭晓后的陪伴演出。
范围：动态立绘、四幕字幕、心情寄语、单签与三连签入口、可选合成和弦。不新增数据库字段或虚构视频素材。

- [x] home.html 增加心情与资源引用；app.js 连接结果及三连签，统一请求锁。
- [x] 浏览器检查正常与特别演出、三连签、异常恢复、手机宽度和减少动态效果。
- [x] 同步本地服务资源，确认 HTTP 可访问。

验收：一次请求期间禁止重复提交；PV 使用对应角色；关闭后无计时或音频残留；无素材时仍有文字；不改变原有抽签概率及每日结果。
