# memory-13 · 谎言十年（lies ten years ago）

一个基于 **Ren'Py** 引擎的二次元视觉小说（AVG）游戏项目，讲述十年前谎言背后的故事。

## 项目组成

- `lies ten years ago/`：Ren'Py 游戏项目
  - `game/`：游戏本体（scripts 脚本、tl 多语言文本、images 立绘与 CG、gui 界面、saves 存档）
  - `tmp/`：本地开发工具与素材（语音下载、COEIROINK 语音合成工具等，不随仓库上传）
- `liestenyearsago-1.0-dists/`：发布的 APK 安装包（com.sekai.lies）

## 运行

使用 Ren'Py SDK 打开 `lies ten years ago` 目录即可运行。

## 说明

- 游戏含多语言文本目录 `game/tl/`，支持多语言。
- 大型语音工具与模型文件（COEIROINK、语音包等）体积较大，未上传至仓库。
