# 第四阶段：卡牌策略与构筑深化（第一批）

日期：2026-10-03。本批交付构筑分析、检索边界修复和4张支援卡审查。不是368张全卡平衡完成；不新增融合玩法。

## 审查发现与处理

原检索的界面回调允许改拿非指定类型，甚至未展示的卡，无合法命中也能补拿。现在仅能选择展示范围内、类型与星级合法的卡；默认卡被消耗、展示牌离开牌库、回合改变或对局结束后不能追加拿牌；只能成功改选一次。换选保持其余展示牌的原顺序。界面将非法候选变暗且禁止鼠标、键盘选择，手机横向列表会把所选牌滚动到可见位置。

旧的两项测试曾将“任意改拿”视为预期，本批改为卡面指定类型，并补充独立回归。共享检索修复覆盖所有 scout/study 卡，不限于4张支援。

## 构筑功能

卡组编辑显示1–4星比例；按实体卡张数、无放回抽样计算初始5张中至少1只低星角色的概率。标注空场、召唤次数未用且无对手干扰的前提，不包含重抽、后手抽牌、检索、特殊召唤，不等于胜率。

灼烧组合显示同时抽到点燃/引爆两类卡的组合概率及缺件提示；合奏显示属性种类与实际留场条件；蓄力、回收与净化给出资源冲突和发动顺序提醒。概率算法使用组合计数，并以独立穷举验证交集与重复实体牌。

## 对局验证

采用生产规则与AI技能/目标评分，使用有步数上限的无界面调度和自动陷阱响应；不是完整浏览器AI策略或真人胜率。每个种子交换双方座位。预先设定本轮模拟警戒区间35%–65%（含边界），仅作为筛查标准。

开发对照种子201–240，每对80局，总240局：

| 对阵（左方胜率） | 改前 | 最终改后 |
| --- | ---: | ---: |
| 合奏 / 蓄力 | 48.75% | 35% |
| 合奏 / 灼烧 | 45% | 35% |
| 蓄力 / 灼烧 | 60% | 60% |

结果说明收敛免费资源显著削弱了合奏，不能用“效果更合理”冒充胜率更好。

最终独立验证种子2001–2100，每对200局、总600局，在此结果之后未再调牌：

| 对阵 | 胜场 | 平均回合 |
| --- | --- | ---: |
| 合奏 / 蓄力 | 70 / 130 | 10.7 |
| 合奏 / 灼烧 | 76 / 124 | 10.0 |
| 蓄力 / 灼烧 | 129 / 71 | 9.8 |

全部结束，无平局、无超时；先手305胜（50.83%），最长40回合；30,287次区域完整性检查通过。合奏35%处于下沿、蓄力对灼烧64.5%靠近上沿，需要真人试玩，不能宣称最终平衡。下一批优先检查合奏建立场面的成本，以及蓄力窗口的反制，而非直接堆伤害。

早期版本使用1001–1100种子曾有2局超过40回合；延长到120回合复查后分别42、51回合结束。随后又调整了两张支援的资源条件，所以这些种子已用作开发验证，不能作为最终独立集。原始报告保留：`strategy-phase-four-holdout.json`、`strategy-phase-four-long-games.json`。其中早期报告的draws包含超时，已修正模拟脚本，最终报告将平局和超时分开。

最终数据：`strategy-phase-four-before.json`、`strategy-phase-four-after.json`、`strategy-phase-four-validation.json`。模拟脚本支持 STRATEGY_REPORT、STRATEGY_SEEDS、STRATEGY_SEED_START、STRATEGY_MAX_TURNS，避免覆盖前阶段基线。
