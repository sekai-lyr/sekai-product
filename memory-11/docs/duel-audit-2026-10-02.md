# 决斗审查与全卡演出验收

2026-10-02。范围：网页决斗控制器、战斗结算引擎、卡牌演出与测试入口。

## 已修复

- 战斗破坏触发返回手牌时，状态重置错误清除了本次战斗免伤；现在在离场前保留结算所需状态。
- 选卡／牌序窗口与动画计时器互相提前解锁；现在交互锁独立维护，未完成选择或陷阱响应时不能结束回合。
- 非法攻击仍进入演出并停留战斗阶段；现在立即终止演出，恢复可取消的主要阶段，不消耗玩家攻击次数。AI 的失败分支也提前退出。
- 怪兽离场后推断所属方导致攻击／破坏动画找错位置；现在在结算前保存双方所属方。同归于尽播放双方破坏动画。
- 陷阱从错误的后场位置发动、同一分镜重复播放；现在使用实际触发卡的 instanceId 定位，单机、AI、远端播放流程分开发动演出与效果反馈。
- 盖放怪兽提前显示卡面及登场效果；盖放移动使用卡背，隐藏状态不播放专属登场或召唤效果演出。

- 6 个页面 × 3 个视口检查通过。
- Maven 打包通过；8091 健康接口与新版本静态入口检查通过。
