# 浏览器版二次元主题与组卡改进

## 界面

统一墨蓝、奶白、珊瑚红和青蓝色彩，漫画网点、实线边框及偏移阴影。覆盖认证、大厅、招募、图鉴、编成、手册、设置及共用弹窗和战斗控件。沿用项目角色插画，未添加前端依赖。布局不改变攻击特效坐标系。

手机卡牌详情改为可滚动单栏，技能名称、触发条件和次数限制可读；详情层高于战斗特效。桌面大厅操作区避让快捷工具栏，浅色导航文字使用深色。

## 功能

- 图鉴和编成共用搜索：卡名、技能名、效果、类型、属性、稀有度；空格分隔的关键词须全部匹配。
- 图鉴选中详情限定在筛选结果中，空结果不再出现旧卡制作按钮；显示结果数量并可重置筛选。
- 图鉴复用战斗详情的技能分块，避免仅显示整段概述。
- 新增起手作战笔记，按实际张数计算不放回抽取5张时至少包含1张1–4星角色的概率，提示高星过多与缺少应对手段；此值不是胜率，也不包含技能检索。
- 修正推荐卡组仅选最高攻击力导致无低星展开的问题；收藏充足时40张卡组优先纳入16张低星角色。
- 推荐与补牌遵守实际持有数量、禁用标记、个别卡牌携带限制。收藏不足时不会凭空补出卡牌。

## 验证

- 405项浏览器规则/功能单元测试通过；40项独立卡牌测试通过。
- 368张卡的481项效果审计通过。本次未据此宣称所有卡组都已达到竞技平衡。
- 真实 Chromium 验证6个大厅页面 × 1440/768/390三种宽度，页面无横向溢出；验证效果搜索、空结果、重置及起手分析。页面使用本地测试收藏，不写入真实账号。
- 攻击选择取消、右键主动技、选择技能目标及定向轨迹的既有浏览器回归通过。
- 目视检查登录、大厅、编成、移动图鉴与移动对局详情截图；无历史像素基线，不作为逐像素回归结论。

截图在 `analysis-contact-sheets/anime-*.png`；浏览器验证脚本为 `.tools/rules-qa/anime-review.mjs`。本次修改浏览器版，不包含 Godot 全卡池移植、线上部署或真实账号登录测试。
