# 逐卡演出接入与验证

## 已接入

- 368张卡均有运行时演出配置；怪兽分登场、攻击、祭品汇聚，魔法/陷阱分配发动演出。
- 21种图形组件按角色主题组合，逐卡分配轨道数、开角、弯曲、顺序和间隔。配置组合不完全重复，共用组件并不意味着368套独立手绘动画。
- 新演出叠加在现有招式上，包括N/R卡；稀有度改变粒子数量，不改变伤害或攻击次数。
- 本地、AI及远端祭品召唤保存素材位置快照；普通/上级召唤按实例ID找本体，不按最后一个卡槽猜测，避免落到衍生物上。
- 图鉴新增“查看专属演出”；详情面板可独立滚动。预览不消耗卡牌。
- 统一视口坐标，最多3层并发，结束清理，减少动态模式简化为短暂淡出。放大主题图形并调整节奏，提高可见性。
- 遗留融合处理器的场上、手牌素材均正确送墓，按送墓而非破坏触发事件；发动中的融合魔法不作为自身替代素材。

## 验证结果

- 浏览器规则/功能测试408项通过，独立卡牌测试40项通过，卡牌效果481项审计通过。

- 图鉴真实点击预览、禁用/恢复按钮、可见粒子及清理检查通过。
