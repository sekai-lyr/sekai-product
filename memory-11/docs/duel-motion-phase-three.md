# 第三阶段：决斗演出、交互与性能

日期：2026-10-03。工程实现及自动回归完成；真实手机帧率、全卡人工美术验收仍待补测。

## 实现

- 增加统一演出生命周期，管理 WAAPI、粒子节点、视觉定时器与动画帧。退出、重开、窗口变化、切后台及动画异常时清理；取消视觉演出不改规则数据、不撤销交互选择锁。
- 抽卡、出牌、回手、回卡组及入墓使用真实源/目标坐标。AI 与远端攻击先完成攻击，再表现破坏；双方破坏同时播放。祭品汇聚使用素材实例坐标，不把衍生物当作召唤落点。
- 提供 0.7、1、1.5、2 倍速度，自动/高/低画质及减少动态。低画质限制粒子、并发、闪光与镜头震动，保留主体和目标反馈。
- 触屏点击角色打开攻击/技能菜单；显示不能发动的原因、蓄力与资源要求。取消攻击选择后可发动技能，不提前消耗攻击次数。修复卡图撑开卡槽、技能按钮被邻槽遮挡的问题。
- 保留现有 368 张卡的演出配置与 586 段分镜；没有宣称重新制作全部独立美术资源，也未新增融合规则。

## 测量

同一台 32 逻辑核主机、Headless Chromium 145.0.7632.6；手机测试为 390px 视口及 4 倍 CPU 节流，不能当作真机帧率。

| 操作 | 原版正常速度 | 新版正常速度 | 新版 2 倍速 |
| --- | ---: | ---: | ---: |
| 抽卡 | 3730 ms | 729 ms | 362 ms |
| 出牌 | 1105 ms | 609 ms | 313 ms |
| 破坏并入墓 | 2115 ms | 1778 ms | 908 ms |

这些是代表场景单次实测，并非统计置信区间。六类代表演出未记录到长任务或残留层；无头浏览器的帧间隔不能证明桌面稳定 60fps 或手机 30fps。

原始数据：`analysis-contact-sheets/motion-before.json`、`motion-after.json`、`motion-transfer-comparison.json`。

## 验证

- `npm run check` 通过；461 项静态目录测试、40 项历史测试、50 个关卡检查通过。
- 368 张卡按适用阶段遍历，覆盖桌面/手机视口、正常/减少动态、双向攻击，共 4960 次检查。验证有限坐标、分镜适用性和清理，不替代逐卡人工观赏。
- 实际页面验证：设置保存、触屏技能入口及禁用原因、取消攻击后技能、抽卡中退出立即重开、旧回调隔离、resize/hidden、并发预算、动画异常。
- 实际对局验证：双方破坏、非法攻击不播放、盖卡信息不泄露、祭品落点及墓地、借用卡组、AI 回合、无奖励结算和重开。
- 图片：`analysis-contact-sheets/motion-mobile-field.png`、`motion-mobile-skills.png`、`tribute-performance.png`。
