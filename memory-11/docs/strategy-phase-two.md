# 第二阶段：代表卡组与战术试炼

更新时间：2026-10-03

## 本阶段交付范围

以三套完整 40 张卡组验证不同打法，并明确调整 11 张现有卡。全卡池仍为 368 张；不将本阶段称作全卡池平衡完成。保留既有插画、稀有度和独立演出。

大厅 → 战术试炼可借用卡组，并独立选择对手卡组。不要求收藏、不写入收藏、不消耗资源、不发奖励、不计战绩。支持正常起手重抽、猜拳、AI 回合、再战与返回大厅。

| 卡组 | 核心决策 | 反制 |
| --- | --- | --- |
| 合奏续航 | 维持不同属性队友，用攻击机会与墓地资源换取抽卡 | 拆掉多属性场面，清理墓地，压制低攻击成员 |
| 蓄力突击 | 放弃当前攻击准备连击，或累积两次电荷后支付 LP 除外 | 准备回合移除、冻结、封印；离场重置蓄力 |
| 灼烧引爆 | 支付 LP 点燃，再选择保留持续伤害或消耗标记立即引爆 | 净化、回手或释放带标记怪兽 |

卡组均含 N/R 支援卡。高稀有度核心通过多段能力、召唤成本和准备回合承担不同职责，而非单纯提高伤害。

额外修复：放弃攻击后不能靠新增连击绕过代价；失效目标不消耗电荷、LP 或发动次数；AI 避免为蓄力或合奏放弃明显的可见致胜攻击；试炼结束不会卡在“正在结算奖励”。

## 固定种子对战

运行：在仓库根目录设置 `STRATEGY_SEEDS=100`、`STRATEGY_SEED_START=21`，执行 `node SekaiGame/scripts/strategy-balance.mjs`。

详细结果：`docs/strategy-balance-results.json`。每对卡组使用 100 个种子、交换先后手，共 200 局；总计 600 局。

| 对阵 | 胜场 | 平均回合 |
| --- | --- | --- |
| 合奏 / 蓄力 | 84 / 116 | 10.9 |
| 合奏 / 灼烧 | 106 / 94 | 10.4 |
| 蓄力 / 灼烧 | 121 / 79 | 9.8 |

600 局均结束，0 平局、0 超时；先手获胜 309 局（51.5%）。31,438 次区域检查未发现卡牌丢失、重复归属或区域超限。核心技能发动计数：合奏 163、一闪 382、电磁炮 66、引爆 137。

模拟采用生产规则引擎和 AI 技能/目标评分，配合有步数上限的无界面调度；陷阱自动响应。它不是完整的浏览器 AI 调度，也不代表真人竞技胜率。初始种子 1–20 用于发现并调整引爆难以成立的问题；21–120 用于扩大验证，并在修正效果重复后重跑，不能再视为完全独立的盲测集。

蓄力对灼烧仍有 60.5% 模拟胜率。下一轮真人试玩重点观察蓄力窗口是否容易打断、净化时机是否清晰、合奏是否过慢，不凭一次模拟承诺最终平衡。
