# 网页决斗规则基线（第一阶段）

版本：2026-10-02。这是当前项目实现的规则表；卡牌明确写出的例外优先。规则数值以 `constants.js` 为准，结算以 `engine.js` 为准，界面演出不得增删手牌或改变结算结果。

## 规则表

| 类别 | 当前行为 | 范围 |
| --- | --- | --- |
| 初始资源 | 双方 8000 LP，起手 5 张；先攻首回合不额外抽卡、不能攻击 | 基础规则 |
| 回合 | 抽卡、准备、主要阶段1、战斗、主要阶段2、结束 | 阶段由操作自动推进属于项目交互 |
| 通常召唤 | 每回合通常召唤与盖放合计 1 次；明确的额外召唤效果例外 | 基础规则 |
| 祭品 | 1～4 星无需解放；5～6 星解放 1 只；7 星及以上通常解放 2 只 | 卡面召唤条件优先 |
| 特殊召唤 | 不消耗通常召唤次数，仍须满足卡牌效果与场地容量 | 基础规则 |
| 攻击机会 | 攻击表示怪兽可在召唤当回合攻击，先攻首回合、状态与卡牌限制除外 | 基础规则 |
| 表示变更 | 当前配置允许召唤当回合尚未攻击时手动变更表示 | **项目自定义**；官方通常禁止召唤当回合手动变更 |
| 攻击表示互攻 | 较弱者被破坏，其控制者承受攻击力差值；同攻且大于 0 时双方破坏；双方 0 攻均不破坏 | 战斗抗性与免伤分别处理 |
| 攻击守备表示 | 攻击力较高通常只破坏守方；贯穿效果例外；攻击力较低时攻方承受差值，攻击者不会因此被破坏；相等均不破坏且无伤害 | 不把战斗破坏免疫等同于免伤 |
| 盖放目标 | 宣言前不显示隐藏身份、攻守值或确定的破坏结论；被攻击翻开后参与伤害计算，翻转效果在伤害计算后处理 | 隐藏信息边界 |
| 直接攻击 | 对方无怪兽且没有禁止直接攻击等限制时允许 | 基础规则 |
| 陷阱 | 盖放当回合不能发动；攻击响应按项目实现处理，单窗口最多 2 张、响应递归最多 3 层 | **简化响应模型**，不等同完整官方连锁与优先权 |
| 主动技 | 按卡面条件与次数限制发动，需目标的效果在确认时再次校验源卡及合法目标 | 项目角色技能 |
| 手牌上限 | 结束阶段丢弃至 6 张；明确效果另行规定 | 基础规则 |
| 胜负 | LP 归零、必须抽卡却无牌可抽、卡面声明的特殊胜利；同时失败可为平局 | 以引擎终局检查为准 |
| 卡组 | 主卡组 40～60；同名至多 3；额外及副卡组各至多 15 | 现有构筑规则 |
| 起手重抽、共鸣 | 按手册与卡面说明；联机不启用起手重抽 | **项目自定义** |

官方核对来源：[规则书入口](https://www.yugioh-card.com/en/rulebook/)、[官方规则书 PDF](https://img.yugioh-card.com/en/downloads/rulebook/SD_RuleBook_EN_10.pdf)、[伤害步骤说明](https://www.yugioh-card.com/eu/play/damage-step-rules/)。这些来源用于区分基础规则与项目自定义内容，不表示本项目已实现完整官方规则。

## 操作状态与取消边界

| 当前操作 | 确认 | 取消 |
| --- | --- | --- |
| 主要阶段1选择攻击者，尚未确认目标 | 引擎接受宣言后提交战斗阶段 | 回主要阶段1，不消耗攻击次数 |
| 已提交攻击或进入陷阱响应 | 继续处理响应和战斗 | 不能倒退主要阶段1；后续选攻击者可取消选择 |
| 选择魔法、技能或墓地目标 | 核对原卡仍在原区域、目标仍合法、回合未过期 | 清理待发动卡、技能索引、后场标记、合法目标；回原阶段 |
| 选择祭品 | 由引擎验证所有素材及召唤卡仍合法 | 仅存在祭品选择时恢复原阶段；普通点击取消不改变阶段 |
| 牌序／选卡／陷阱窗口 | 回调只处理一次，旧回合回调不执行新回合操作 | 须完成当前窗口，不能跳阶段或结束回合绕过 |
| 结束回合确认与弃牌 | 回调只生效一次 | 不允许旧回合确认结束新回合 |

已实际攻击后继续出牌会进入主要阶段2；该阶段不能再次进入战斗。单纯动画报错不会撤销已发生的规则结算。

## 结算与演出约束

- 引擎先结算抽卡，演出只读取抽到的卡；禁止为了隐藏动画中的手牌而临时从真实手牌中移除卡。
- 普通召唤、回合抽卡、普通／盖放魔法、攻击响应陷阱和攻击者败北演出使用各自完成锁；完成或失败只释放本段锁。
- 旧计时器和交互窗口各自维护，不允许通过清空旧计时器释放尚未完成的异步演出。
- 部分旧粒子、场地魔法等仍使用限时展示锁；第一阶段没有重写整个特效系统。
- 普通攻击的视觉尾帧不占用后续合法攻击机会，沿用已有连续攻击行为。
- 每次成功的引擎攻击生成只含复制值的 `report`，并记录 `onBattleResolved`；失败、等待响应和卷回不生成“已结算”报告。
- 报告区分宣言时攻守值、实际战斗伤害及包含触发效果的总 LP 变化。宣言值并非承诺后续响应不会改变数值。
- 预览是公开场面的基础估算，不执行隐藏效果或未来响应。

- `SekaiGame/src/main/resources/static/test/duel-foundation.test.js`：选择、过期回调、重复确认、独立完成锁、报告及 32 种基础攻守组合。

- `.tools/rules-qa/browser-check.mjs`、`duel-audit.mjs`：实际点击、攻击取消、技能切换、反击、破坏与盖放保密。

本阶段未将结算迁到服务端，未承诺断线恢复，也未完成双端联机全流程验收；这些仍属后续联机阶段。
