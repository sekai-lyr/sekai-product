问题：全卡牌统一的“演出语言”选哪一种？

下面三个舞台演示同一套招式（火刀斩 / 火球 / 虚式）在三种风格下的效果。每个舞台可切换招式重播； 看完后点击你偏好的整张风格卡片，然后在终端告诉我你的想法（可以要求混搭，例如“C 的卡图特写 + A 的清晰刀弧”）。

A招式剪影

用清晰的招式形状还原原著：火焰刀弧、火球、紫色球体与光柱。粒子克制、不叠全屏光效，最“看得出是什么招”。
