实机演示：新特效接在你现在的战斗界面上

只动特效层。没有改布局、没有改规则、没有改任何界面元素——特效直接在你现有战场的上层播放（这是从你游戏的实际运行画面录制的）。

录制内容：现有界面 → 炭治郎攻击切入 → 五条悟爆发切入 → 回到现有界面

这段演示里发生了什么

  • 炭治郎攻击（近战）：卡图原画推近 → 负片/黑白冲击帧 → 斩线扫过 → 余烬飞散 → 招式名「火之神神乐」打出，然后回到战场结算。
  • 五条悟·虚式茈（远程/领域）：原画充能推近 → 咒力粒子上升 → 收束环 → 紫白爆发 + 电影黑边 → 招式名「虚式 · 茈」。
  • 所有演出都盖在你现在的战场、手牌、日志、按钮之上，播完即恢复，不改任何布局坐标。

与七圣召唤的对齐点（后续所有角色都按这个标准执行）

  • 短：一次招式约 1.5～2.5 秒，不打断对局节奏；
  • 专属：每个角色用自己的卡图和招式名，一眼能认出是谁的招；
  • 同帧结算：招式结束的瞬间接伤害数字、LP 变化、破坏反馈。
