主控 2D 人物模型 · 标定与预览

这一页直接用游戏运行时的同一套模块（controller-mesh.js / controller-rigs.js / controller-mesh-model.js），所以这里看到的形变与游戏里完全一致。
打开「骨架叠加」可以检查骨骼枢轴是否落在正确的人体部位上；拖动滑杆可以单独试每个姿态参数。

Live2D Cubism 技术验证 （官方示例模型 Hiyori · 非出场角色）

这一格走的是真 Live2D 运行时：live2dcubismcore.min.js 解析 .moc3，cubism-framework.esm.js 负责动作 / 物理 / 自动眨眼 / 呼吸，主控事件映射到模型自带的动作组。
如果这里显示「装配失败」或「WebGL 不可用」，说明当前环境跑不了 Cubism，游戏本身不受影响（会静默回退静态图后端）。

怎么调 rig：骨架与影响范围定义在 js/controller-rigs.js，坐标是 归一化 alpha 包围盒坐标（0..1，y 向下）。红色=身体骨骼，橙色=弹簧链骨骼， 圆圈=该骨骼的影响半径，青色框=矩形门控区域（道具/布料用）。
改完怎么验证：命令行跑 node SekaiGame/tools/verify-controller-mesh.mjs 看数值验收，跑 node SekaiGame/tools/render-controller-mesh.mjs --debug-rig 输出骨架叠加 PNG，或直接刷新本页看实机效果。
