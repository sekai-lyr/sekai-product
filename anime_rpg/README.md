# 异世界冒险 - 二次元RPG

一款使用Godot 4开发的二次元风格异世界转生RPG冒险游戏。

## 游戏特色

- **即时回合制战斗 (ATB系统)**: 速度影响行动条填充，战斗节奏紧张刺激
- **Live2D角色**: 使用Live2D Cubism技术的角色动画
- **异世界转生故事**: 主角穿越到异世界，展开冒险之旅
- **丰富的探索内容**: 村庄、野外、地下城等多个区域

## 角色介绍

- **主角 (aidang_2)**: 从现代穿越到异世界的勇者
- **haru**: 异世界的神秘少女，主角的向导和伙伴

## 游戏系统

### 战斗系统
- ATB行动条：速度越快，行动越频繁
- 五种指令：攻击、技能、防御、道具、逃跑
- 多样化的技能系统

### 探索系统
- WASD/方向键移动
- 空格键交互
- 随机遇敌

### 对话系统
- 打字机效果
- 角色表情切换
- 选项分支影响好感度

## 开发环境

- **引擎**: Godot 4.x
- **语言**: GDScript
- **Live2D SDK**: Cubism SDK for Native

## 项目结构

```
anime_rpg/
├── assets/          # 游戏资源
├── scenes/          # 场景文件
├── scripts/         # 脚本文件
├── data/            # 数据文件
├── resources/       # Godot资源
└── addons/          # 插件
```

## 运行方法

1. 使用Godot 4打开 `project.godot`
2. 按F5运行游戏
